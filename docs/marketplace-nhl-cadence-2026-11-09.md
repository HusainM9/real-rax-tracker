# NHL Marketplace coverage and scheduled cadence

The owner reported missing NHL alerts, around fifteen listings checked in the scan log and eight-minute intervals instead of four. The specific example was a Rare Jack Eichel auction with a 25 RAX/rating target, using the default alert limit rather than a player override.

## Findings

Bounded read-only account alert storage inspection found ten selected NHL players and four other selected players. The saved NHL rule was enabled for catalog season 2027, all rarities with Rare–Legendary target-price filtering, and a default 25 RAX/rating maximum. Eichel had no overrides. Offline tests confirmed that this default is inherited, Rare/Epic target auctions at 25 qualify, and an over-limit target is excluded. No saved rule was changed.

The old log counted listings across every sport, not NHL alone. A normal scheduled run at `2026-11-09T03:04:01.614Z` recorded ten NHL requests, all with zero returned listings, without a rejection/error/cursor warning. The four other player feeds returned eleven listings. Thus the empty NHL feed occurred before rarity and price matching.

The tracker represents NHL 2026–27 with catalog end-year 2027. Marketplace had passed this year directly to Real. The existing NHL adapters use start-year 2026. Request construction and listing-season comparison now use one shared NHL-only conversion, while saved rules, displayed seasons and notification metadata retain catalog year 2027. Other sports are unchanged. There is no alternate-season fallback or extra feed request. The earlier NHL routing test proved sport/ID construction but did not verify a live Marketplace season contract; its expected query year has been corrected.

The exact four-minute cooldown started after variable arrival/storage latency. A following scheduled tick just before expiry was acknowledged as skipped, losing another four minutes. Scheduled admission now waits once for at most five seconds when the cooldown is nearly expired, then passes through the existing atomic gate. The cooldown is never shortened; manual/duplicate/legacy two-minute arrivals still skip, overlap ownership is preserved, and cancellation clears the waiter. No scheduler or provider retry policy changed.

Existing scan history now includes controlled per-feed counts, numeric requested/returned seasons and rejection/cursor flags. The page groups counts by sport and season so NHL coverage is visible. Old aggregate-only history still renders. No raw responses, private URLs or credentials are stored in these diagnostic fields.
